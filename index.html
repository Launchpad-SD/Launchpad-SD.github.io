为什么是 Repo

为什么是 Repo，
而不是 Agent 或 Skill。

盛大 Launchpad 用仓库承载知识。Repo 不是开箱即用的产品：有些需要自带 API key，内部仓库需要权限，请先读 README。

01

可 fork · 可审计

代码、提示词、数据处理逻辑都摊开，能读能改，不是黑盒。

02

有版本

git 记录每次改动，可回滚、可对比，知识跟着 commit 一起演进。

03

不绑定 Agent

同一个仓库，可以在 Claude Code、Codex 或任何能读文件、跑命令的 agent 里用。

04

PR 共建

新案例、新资源、bug 修复，提 PR 或 issue，review 后合并。

Launchpad 的选择

知识和代码，
一起迁移。
不锁在平台里。

01 / PORTABLE

可迁移

知识和代码放在同一个仓库里，不锁在某个平台或 SaaS 账号中，换工具也能带走。

02 / CONTAINER

Repo 是容器

仓库里本来就能装 skill（如 product-video-factory）、MCP server（如 sv-gtm-advisor、github-signal）和 agent 工作流。

怎么用

在 Launchpad 仓库上，
四步开始。

示例：git clone https://github.com/Launchpad-SD/awesome-gtm-resources.git，在目录里运行 claude 或 codex。

01

Star / Watch

关注公开仓库，跟进每周更新。

02

Clone / Fork

直接 clone 阅读；要修改或共建，先 fork。

03

接进 Claude Code / Codex

在仓库目录里打开 agent 读 README，或按 README 接入 skill / MCP。sv-gtm-advisor 需找 Bei 要个人安装文件。

04

PR / Issue

补充案例、修复问题、分享资源；awesome-gtm-resources 欢迎直接丢链接。
